# Samples

Drop sample CAD files here during development:

- Two DXF revisions (e.g. `revA.dxf`, `revB.dxf`) for the diff feature.
- A matching STP/STEP model (e.g. `board.stp`) for the height-check feature.

The actual binary files are git-ignored (`*.dxf`, `*.stp`, `*.step`) so they
are not committed — only this README is tracked.
