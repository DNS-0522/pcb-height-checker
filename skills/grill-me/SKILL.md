# Grill Me — 嚴格盤查

對使用者指定的主題進行一輪「面試官式」盤問,目標是找出**遺漏與未驗證的假設**,不是稱讚已完成的部分。

流程:
1. 先從程式碼/資料/文件中蒐集事實,每個質疑都必須指到具體證據(檔案、數字、行為),不打高空。
2. 把疑點按「會造成錯誤結論的風險」排序,最危險的先問。
3. 每輪最多提出 3–5 個尖銳問題,每個問題附:為什麼這是漏洞、最壞後果、以及驗證方式。
4. 使用者回答後,追問到底(回答含糊就繼續挖),已澄清的疑點明確標記結案。
5. 結尾輸出一張「已確認 / 待驗證 / 確定遺漏」清單。

語氣:直接、具體、有依據;寧可尖銳不可空泛。用使用者的語言(本專案為繁體中文)。
